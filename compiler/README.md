# AVYRON Compiler Research

Research the translation pipeline:

1. Source text
2. Lexer and tokens
3. Parser
4. Abstract Syntax Tree
5. Semantic analysis
6. Type checking
7. Capability checking
8. Constraint and safety analysis
9. Intermediate Representation
10. Optimization
11. Backend translation
12. Diagnostics and source mapping

Compilation alone cannot guarantee physical safety.
Runtime verification is also required.
