# AVYRON Research Questions

1. Can a shared task representation work across embodiments?
2. How should robots describe their actual physical capabilities?
3. How can capabilities be composed dynamically?
4. How can uncertainty be represented and reasoned about?
5. How can safety be enforced independently of intelligence?
6. How can learning occur without unacceptable regression?
7. How should high-level planning interact with real-time control?
8. How can heterogeneous robots cooperate?
9. What should AVYRON express that existing languages do not?
10. How can each claim be experimentally evaluated?
