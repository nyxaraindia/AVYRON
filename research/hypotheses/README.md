# AVYRON Research Hypotheses

Candidate hypotheses requiring investigation:

- H1: A shared task representation can support multiple embodiments.
- H2: Capability-aware planning can reduce infeasible action plans.
- H3: Dynamic module selection can reduce unnecessary computation.
- H4: Explicit safety contracts can reduce unsafe execution.
- H5: Controlled learning can improve performance while limiting regression.
- H6: A dedicated robotics language can reduce programming effort.

For every hypothesis document its claim, prior work, method,
baselines, metrics, results and limitations.
