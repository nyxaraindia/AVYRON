## 3. Concepts Studied

### 3.1 Algorithm

An algorithm is a sequence of defined steps used to solve a problem.

Research relevance:

Robotic intelligence requires structured procedures for completing tasks.

### 3.2 Input–Process–Output

Input represents received information.

Process represents operations performed on the information.

Output represents the result.

Research relevance:

This model helps organize the flow of information through robotic components.

### 3.3 Problem Decomposition

Problem decomposition divides a large task into smaller tasks.

Research relevance:

Complex robotic tasks can contain multiple dependent operations.

Example:

Deliver a box:

1. Locate the box.
2. Verify reachability.
3. Pick up the box.
4. Verify successful pickup.
5. Navigate to destination.
6. Place the box.
7. Verify delivery.

### 3.4 Sequence

Operations execute in an ordered manner.

### 3.5 Selection

Conditions determine which operation should execute.

### 3.6 Repetition

Operations repeat while required conditions remain true.

Research relevance:

Robots need repeated observations and decisions because their environments can change.

### 3.7 Pseudocode

Pseudocode describes algorithm logic independently of a specific programming language.

Research relevance:

It helps define behaviour before implementing AVYRON language syntax.

## 5. Obstacle-Avoidance Algorithm

Scenario:

A mobile robot is moving towards a destination and detects an obstacle.

Proposed simplified procedure:

1. Receive sensor information.
2. Estimate obstacle distance.
3. Evaluate whether the path is blocked.
4. Stop if an obstacle requires intervention.
5. Evaluate alternative routes.
6. Check whether an alternative route is feasible.
7. Request safety authorization.
8. Execute only an authorized action.
9. Observe the result.
10. Update the environment understanding.
11. Repeat.

Important limitations:

- Sensor uncertainty is not yet formally modelled.
- No motion-planning algorithm has been selected.
- No collision-avoidance guarantees exist.
- No physical or simulated tests have been conducted.
