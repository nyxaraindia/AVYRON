## 2. What Is a Condition?

A condition is a question or expression that evaluates to either:

- TRUE
- FALSE

Examples:

- Is battery above 50%?
- Is the box reachable?
- Is the gripper working?
- Is the robot damaged?

Computers evaluate conditions and use the results to select actions.

## 3. Comparison Operators

| Operator | Meaning | Example |
|---|---|---|
| `>` | Greater than | `10 > 5` |
| `<` | Less than | `3 < 8` |
| `==` | Equal to | `5 == 5` |
| `!=` | Not equal to | `5 != 3` |
| `>=` | Greater than or equal | `10 >= 10` |
| `<=` | Less than or equal | `5 <= 8` |

Important:

- `=` assigns a value.
- `==` compares two values.

## 4. Logical Operators

### AND

All conditions must be TRUE.

Example:

`battery_sufficient AND gripper_working`

### OR

At least one condition must be TRUE.

Example:

`camera_working OR lidar_working`

Whether one working sensor is sufficient depends on the task requirements.

### NOT

Reverses a condition.

Example:

`NOT robot_damaged`

## 5. Truth Table

| A | B | A AND B | A OR B |
|---|---|---|---|
| TRUE | TRUE | TRUE | TRUE |
| TRUE | FALSE | FALSE | TRUE |
| FALSE | TRUE | FALSE | TRUE |
| FALSE | FALSE | FALSE | FALSE |

## 6. IF, ELSE and ELIF

Python uses conditional statements to make decisions.

### IF

```python
if battery > 20:
    print("Battery sufficient")
```

### IF and ELSE

```python
if battery > 20:
    print("Continue")
else:
    print("Recharge")
```

### IF, ELIF and ELSE

```python
if battery > 70:
    print("High battery")
elif battery > 20:
    print("Medium battery")
else:
    print("Low battery")
```

Python evaluates conditions from top to bottom and executes the first matching branch.

## 7. AVYRON Example

```python
battery = 80
gripper_working = True

if battery >= 30 and gripper_working:
    print("Candidate for task")
else:
    print("Do not assign task")
```

This example checks battery and gripper condition.

Passing these checks only makes the robot a candidate. It does not provide final safety authorization.

AVYRON must also consider reachability, environment, uncertainty and independent safety authorization.
