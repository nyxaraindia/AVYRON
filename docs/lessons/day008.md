## 1. Objective

Understand how computers organize information using data structures and how AVYRON can store information about different robot designs.

## 2. What is a data structure?

A data structure is a way of organizing and storing information so that a computer can access and manage it efficiently.

AVYRON may eventually manage hundreds or thousands of different robots. It needs an organized way to store their information.

## 3. Python Lists

A list stores multiple items in an ordered collection.

```python
robots = ["Humanoid", "Robot Arm", "Drone", "Wheeled Robot"]
```

List positions begin at index 0.

```python
print(robots[0])
```

Output:

```text
Humanoid
```

Useful list operations:

```python
robots.append("Quadruped")
robots.remove("Drone")
```

- `append()` adds an item.
- `remove()` removes an item.
- Indexing accesses an item.
- A `for` loop can examine each item.

## 4. Python Dictionaries

A dictionary stores information as key-value pairs.

```python
robot = {
    "name": "AVYRON-R01",
    "battery": 85,
    "carrying_capacity": 10,
    "gripper_working": True
}
```

Access a value:

```python
print(robot["battery"])
```

Update a value:

```python
robot["battery"] = 70
```

Add information:

```python
robot["type"] = "Humanoid"
```

A dictionary is useful when information has labels.

## 5. Lists versus Dictionaries

| List | Dictionary |
|---|---|
| Stores ordered items | Stores key-value pairs |
| Uses indexes | Uses keys |
| Good for collections | Good for labelled information |

A list and dictionary can be combined.

## 6. List of Dictionaries

This is a useful way to represent multiple robots.

```python
robots = [
    {
        "name": "Robot A",
        "battery": 90,
        "carrying_capacity": 8
    },
    {
        "name": "Robot B",
        "battery": 75,
        "carrying_capacity": 2
    },
    {
        "name": "Robot C",
        "battery": 60,
        "carrying_capacity": 10
    }
]
```

Access Robot C's carrying capacity:

```python
print(robots[2]["carrying_capacity"])
```

Add another robot:

```python
robots.append({
    "name": "Robot D",
    "battery": 95,
    "carrying_capacity": 5
})
```

## 7. Robot Capability Profiles

AVYRON needs structured robot profiles.

An illustrative profile:

```python
robot = {
    "id": "AVYRON-R01",
    "name": "Warehouse Robot",
    "type": "Wheeled",
    "battery": 85,
    "sensors": ["Camera", "LiDAR"],
    "actuators": ["DC Motor", "Gripper"],
    "capabilities": ["Navigation", "Object Detection", "Grasping"],
    "limits": {
        "carrying_capacity": 10,
        "maximum_speed": 2
    },
    "condition": {
        "camera_working": True,
        "gripper_working": True
    }
}
```

This is an educational example, not the final AVYRON data model.

## 8. Using Robot Information

A simple carrying-capacity check:

```python
for robot in robots:
    if robot["carrying_capacity"] >= 5:
        print(robot["name"], "is a candidate")
```

This checks only carrying capacity. It does not prove that the robot can safely complete a task.

Other checks include:

- Battery and battery health.
- Sensor condition.
- Reachability.
- Gripper or other required equipment.
- Environment.
- Physical limitations.
- Independent safety authorization.
