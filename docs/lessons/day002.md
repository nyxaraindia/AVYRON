## 2. What Is a Robot Capability?

A capability means something a robot is able to do, considering
its hardware, software, current condition and environment.

Example:

A humanoid robot may have:

- Two cameras.
- Two arms.
- Two hands.
- Walking legs.
- A battery.
- A computer.

Potential capabilities include:

- Seeing objects.
- Walking.
- Picking up objects.
- Carrying objects.
- Moving around obstacles.

However, having a capability does not mean the robot can always
use it.

For example, a humanoid may have hands but be unable to grasp an
object if its fingers are damaged.

### Important Distinction

| Term | Meaning |
|---|---|
| Hardware | Physical components the robot has |
| Capability | What the robot can do |
| Limitation | What restricts its abilities |
| Condition | Current state of the robot |
| Environment | Surroundings in which it operates |

AVYRON must understand all five.

## 3. Sensors — How Robots Receive Information

Sensors are components that collect information from the environment
or from the robot's internal state.

Examples:

| Sensor | Purpose |
|---|---|
| Camera | Collects images and visual information |
| LiDAR | Measures distance and surrounding geometry |
| Ultrasonic | Measures distance using sound waves |
| Microphone | Collects sound |
| IMU | Measures acceleration and angular motion |
| Force sensor | Measures applied force |
| Touch sensor | Detects physical contact |

### Example

A robot sees a box using its camera.

Can the camera directly tell the robot exactly how heavy the box is?

No.

A normal camera provides visual information. It does not directly
measure the object's weight.

Additional information may come from:

- A force measurement.
- A weighing sensor.
- Reliable external data.

Important AVYRON principle:

Do not confuse what a robot observes with what it actually knows.

---

## 4. Actuators — How Robots Perform Actions

Sensors collect information.

Actuators convert commands into physical actions.

Examples:

| Actuator | Action |
|---|---|
| Servo motor | Controls angular position |
| DC motor | Produces rotational movement |
| Linear actuator | Produces linear movement |
| Gripper | Holds or releases objects |
| Drone motor | Rotates a propeller |

### Robotic Arm Example

1. Camera detects the box.
2. Intelligence decides to reach for it.
3. Motors move the arm.
4. Gripper closes around the box.
5. Sensors check the result.

Remember:

Sensors receive information.
Actuators produce physical action.

## 5. Physical Constraints

Every robot has physical limits.

Consider an illustrative robotic arm:

| Property | Example value |
|---|---:|
| Maximum payload | 15 kg |
| Maximum reach | 1.2 metres |
| Gripper | Available |
| Position range | Limited by joint design |
| Power | Electrical |

These are example values, not manufacturer specifications.

### Task A

Pick up a 5 kg box.

Potentially feasible, subject to reach, gripper and safety checks.

### Task B

Pick up a 20 kg box.

Not feasible under the stated 15 kg payload limit.

### Task C

Pick up a 5 kg box located 2 metres away.

Not reachable if the required grasp position is outside the arm's
stated 1.2 metre reach.

Important:

Maximum reach and maximum payload may not be achievable simultaneously.
Real robot specifications can depend on configuration and operating conditions.

A task may fail because of:

- Weight.
- Distance.
- Movement limitations.
- Sensing limitations.
- Energy limitations.
- Safety restrictions.

## 6. Five Introductory Capability Categories

### 1. Perception Capability

What can the robot detect or measure?

Examples:
- Object detection.
- Distance measurement.
- Sound detection.

### 2. Manipulation Capability

Can the robot:
- Grasp?
- Hold?
- Lift?
- Release objects?

### 3. Mobility Capability

Can the robot:
- Walk?
- Fly?
- Roll?
- Navigate?

### 4. Computational Capability

What processing, memory and communication resources are available?

### 5. Operational Capability

How much energy, operating time and resource capacity does it have?

## 7. Introducing the Robot Capability Profile

A proposed research concept for AVYRON is the Robot Capability Profile.

Imagine AVYRON connects to a new robotic arm.

It receives an illustrative description:

ROBOT:
    Type: Robotic Arm

SENSORS:
    Camera: Available
    Force Sensor: Available

ACTUATORS:
    Electric Motors: Available
    Gripper: Available

LIMITS:
    Maximum Payload: 15 kg
    Maximum Reach: 1.2 m

RESOURCES:
    Power: Electrical
    Energy: Limited

STATUS:
    Operational

This is an illustrative data format, not the final AVYRON Language.

The proposed idea is that AVYRON can inspect a robot's capability
profile before planning a task.

### Important Research Problem

How can AVYRON know that the information is accurate and up to date?

A robot may have:

- A damaged gripper.
- A depleted battery.
- A faulty sensor.
- A communication problem.

A capability description must not automatically be treated as proof
of the robot's current condition.

## 8. Practical Reasoning Exercise

### Robot Specifications

Consider a small autonomous wheeled robot.

| Property | Value |
|---|---|
| Camera | Available |
| Gripper | Available |
| Wheels | Available |
| Maximum payload | 3 kg |
| Maximum speed | 1 m/s |
| LiDAR | Not available |

Task:

"Find a 2 kg box, pick it up and transport it to another location."

### Learner's Answers

1. Can it visually search for the box?
   Answer: Yes.

2. Can it potentially pick up the box?
   Answer: Yes.

3. Can it move while carrying the box?
   Answer: Yes.

4. What important information is missing?
   Answer: Distance it can reach.

5. Can AVYRON guarantee the task will succeed?
   Answer: Yes, partially.

### Review and Corrections

#### Question 1 — Vision

Correct.

The camera can provide visual information to search for the box.

However, lighting, camera quality and object detection capability matter.

#### Question 2 — Grasping

Potentially correct.

The box weighs 2 kg, below the stated 3 kg payload limit.

However, AVYRON must verify gripper strength and payload specifications.

#### Question 3 — Transportation

Potentially correct.

Wheels provide mobility, but AVYRON must also check:

- Whether the floor is suitable.
- Whether motors can handle the load.
- Whether the robot is stable.
- Whether the route is clear.

#### Question 4 — Missing Information

Correct.

The learner identified distance and reachability.

Other missing information includes:

- Distance to the box and destination.
- Gripper force.
- Battery level.
- Terrain and obstacles.
- Sensor reliability.

#### Question 5 — Guaranteed Success?

The learner answered: "Yes, partially."

This demonstrates useful reasoning.

The task appears feasible based on the supplied information,
but success cannot be guaranteed.

Important distinction:

Feasible does not mean guaranteed.
