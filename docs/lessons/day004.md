## 2. What Is an Algorithm?

An algorithm is a sequence of clearly defined steps used to solve a problem or complete a task.

Example: Making tea.

1. Take a vessel.
2. Add water.
3. Heat the water.
4. Add tea powder.
5. Add milk and sugar.
6. Boil the mixture.
7. Filter and serve.

These steps form an algorithm.

An algorithm describes the logic of solving a problem.

---

## 3. Algorithm vs Program

| Algorithm | Program |
|---|---|
| Sequence of steps to solve a problem | Implementation using programming syntax |
| Focuses on logic | Focuses on executable instructions |
| Can be written in plain language | Written using a programming language |
| Independent of a particular language | Depends on language and execution environment |

Example algorithm:

1. Receive two numbers.
2. Add them.
3. Display the result.

Example Python program:

```python
a = 10
b = 20

result = a + b

print(result)
```

Output:

```text
30
```

The algorithm describes the solution. The program implements it.

## 4. Input–Process–Output (IPO)

Most basic computational operations can be understood through three parts.

### Input

Information received by a system.

Example: Two numbers, 10 and 20.

### Process

Operations performed on the input.

Example: Add 10 and 20.

### Output

The result produced.

Example: 30.

General representation:

INPUT
  |
  v
PROCESS
  |
  v
OUTPUT

Robotics example:

- Input: Camera detects an obstacle.
- Process: Estimate its distance and evaluate possible routes.
- Output: An appropriate movement command.

Real robotics systems also require feedback, safety checks and continuous processing.

## 5. Problem Decomposition

Problem decomposition means breaking a large problem into smaller problems.

Example:

Task: Make a robot deliver a box.

Smaller tasks:

1. Identify the box.
2. Locate the box.
3. Check whether the robot can reach it.
4. Move towards the box.
5. Pick up the box.
6. Verify successful pickup.
7. Navigate to the destination.
8. Place the box.
9. Verify delivery.

Advantages:

- Easier implementation.
- Easier testing.
- Easier debugging.
- Better organization.
- Reusable components.

For AVYRON, decomposition can help create reusable task and capability components.

## 6. Three Important Algorithm Structures

### 6.1 Sequence

Sequence means executing instructions in order.

Example:

1. Read battery level.
2. Check destination.
3. Calculate route.
4. Start movement.

### 6.2 Selection

Selection means choosing between different paths based on a condition.

Example:

IF battery is low:
    Go to charging station.
ELSE:
    Continue the task.

Selection allows a robot to make conditional decisions.

### 6.3 Repetition

Repetition means executing a process repeatedly.

Example:

WHILE destination is not reached:
    Observe surroundings.
    Update position.
    Decide next movement.

Repetition is important because robots operate in changing environments.

## 7. First Robot Algorithm: Obstacle Avoidance

Situation:

A mobile robot is moving forward and detects an obstacle.

Algorithm:

1. Receive sensor information.
2. Estimate obstacle distance.
3. Check whether the obstacle is close.
4. If the path is clear, continue.
5. If an obstacle is detected, stop.
6. Evaluate alternative routes.
7. If a safe route exists, select it.
8. Request safety authorization.
9. Execute only an authorized action.
10. Observe the result.
11. Update the environment understanding.
12. Repeat.

This is a simplified teaching algorithm.

Real obstacle avoidance requires validated sensing, motion planning, control and independent safety mechanisms.

## 8. Pseudocode

Pseudocode describes algorithm logic using human-readable instructions without requiring exact programming syntax.

Conceptual AVYRON-style pseudocode:

```text
START

SET goal = "Reach destination"

WHILE goal is not completed:

    RECEIVE sensor information

    UNDERSTAND current environment

    IF obstacle is detected:

        STOP movement

        EVALUATE alternative routes

        IF safe route is available:

            SELECT alternative route

            REQUEST safety authorization

            IF action is authorized:
                EXECUTE movement
            ELSE:
                REMAIN STOPPED

        ELSE:

            REMAIN STOPPED

    ELSE:

        SELECT forward movement

        REQUEST safety authorization

        IF action is authorized:
            EXECUTE movement
        ELSE:
            REMAIN STOPPED

    RECEIVE feedback

    UPDATE environment understanding

END WHILE

END
```

This is conceptual pseudocode, not executable AVYRON language syntax.

## 9. Algorithm Efficiency

Algorithm efficiency describes how much time and computational resources an algorithm needs.

Important future topics:

- Time complexity.
- Space complexity.
- Search algorithms.
- Pathfinding.
- Optimization.
- Resource consumption.

Example:

Robot A searches every warehouse shelf one by one.

Robot B uses a map to prioritize likely locations.

Robot B may find the object faster, but an outdated map can lead to incorrect decisions.

A good algorithm should solve the problem correctly while using reasonable time and resources.
