# AVYRON Language Research

Research a hybrid, readable, intelligence-oriented robotics language.

Topics:

- Language philosophy and design goals
- Declarative task descriptions
- Imperative control escape hatches
- Syntax and formal grammar
- Abstract syntax tree
- Type system and capability-aware types
- Physical units and dimensional correctness
- Uncertainty representation
- Temporal and resource constraints
- Safety contracts
- Error handling and concurrency
- Standard library and examples

Justify language design against existing languages and DSLs.
